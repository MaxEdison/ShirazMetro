# 🚇 شیرازمترو | ShirazMetro

### یک راه ساده، سریع و جامعه‌محور برای مشاهده زمان‌بندی مترو شیراز

**شیرازمترو** یک وب‌اپلیکیشن متن‌باز برای مشاهده و بررسی **زمان‌بندی مترو شیراز** است که با تمرکز بر سادگی، سرعت و کاربرد واقعی ساخته شده است.

فقط کافیست خط، مبدا، مقصد و وضعیت تعطیل بودن روز را مشخص کنید و زمان حرکت قطارها را ببینید؛ بدون نصب برنامه، بدون ساخت حساب کاربری و کاملا آزاد/رایگان


---

## امکانات

-  مشاهده زمان‌بندی مترو شیراز
-  پشتیبانی از **خط ۱ و خط ۲**
-  نمایش زمان حرکت و رسیدن
-  تفکیک قطارهای **گذشته، آینده و نزدیک/جاری**
-  رابط کاربری سبک با تم تاریک
-  سرعت بارگذاری بالا و frontend سبک
-  بدون نیاز به حساب کاربری یا نصب

---

##  شیرازمترو چگونه کار می‌کند؟

ساختار شیرازمترو عمداً ساده نگه داشته شده است.

پروژه از دو بخش اصلی تشکیل شده است:


مرورگر مسئول رابط کاربری و تعامل با کاربر و API اطلاعات مترو و محاسبات لازم مربوط به زمان‌بندی و سفر را فراهم می‌کند.

 ظاهر پروژه عمداً بدون فریم‌ورک سنگین و بدون معماری پیچیده ساخته شده تا کد پروژه قابل فهم، سبک و قابل مشارکت باقی بماند.

##  اجرای پروژه به‌صورت Local


```bash
git clone https://github.com/MaxEdison/ShirazMetro.git
cd ShirazMetro
git switch gh-pages
```

سپس پروژه را با یک HTTP server ساده اجرا کنید.

برای مثال با Python:

```bash
python3 -m http.server 8080
```

سپس در مرورگر:

```text
http://localhost:8080
```

>  برای توسعه و تست، پروژه را با یک HTTP server اجرا کنید و صرفاً فایل `index.html` را مستقیماً باز نکنید.

##  API

رابط برنامه نویسی یا API این پروژه با ExpressJS بازنویسی شده و روی شاخه (branch) api در دسترس و قابل مشاهده است.
همچنین فرایند build و کانتینرسازی Backend کاملا توسط Github Actions پیاده سازی شده و قابل مشاهده می باشد.

##  چرا متن‌باز؟

اطلاعات مربوط به حمل‌ونقل عمومی باید تا حد امکان قابل دسترسی، بررسی و بهبود باشد.

شیرازمترو به‌عنوان یک نرم‌افزار آزاد منتشر شده تا توسعه‌دهندگان و کاربران بتوانند:

- کد منبع را بررسی کنند
- نحوه کار پروژه را یاد بگیرند
- پروژه را بهبود دهند
- اطلاعات اشتباه را اصلاح کنند
- قابلیت‌های جدید اضافه کنند
- نسخه‌های تغییر یافته را مطابق شرایط مجوز منتشر کنند

این پروژه **برای جامعه و توسط جامعه** ساخته شده است.
